## 生体信号データの形式と読み込み

本実験では，PhysioNet 2018の生体信号を，研究室のSleep-Data-Hub標準形式に変換したデータを使います．
EDF/BDFの読み込みや標準形式への変換は済んでいるため，学生が実装する必要はありません．

データは `/data/ise_data` にあります．`physionet2018.sqlite` はコホートのメタデータ，
`r-*.npz` は各記録の信号です．この場所は実験用コンテナ内でも同じパスで，読み取り専用です．
生体信号データを自身のリポジトリへコピーしたり，GitHubへPushしたりしないでください．

標準形式のNPZは，チャンネルごとの信号を `signal_concat`，境界を `signal_offsets`，
信号名を `signal_info`，サンプリング間隔を `signal_sampling_interval_ms` に保存しています．
ファイル内にエポック化された `signal` 配列はありません．
本実験では，テンプレートに同梱した **Sleep-Data-HubのLoader** を使って読み込みます．

PhysioNet 2018には正解ステージのある記録と，正解のない記録が混在します．
以下の例は，正解のある記録を自動的に1つ選びます．
テンプレートのルートディレクトリ（コンテナでは `/workspace`）で実行してください．

```python
from src.datasets.loader.standard_sleep_data import find_example_file, load_sleep_record

npz_path = find_example_file("/data/ise_data")
print(npz_path)
record = load_sleep_record(npz_path)
signals = record.signals

print(record.channel_names)
# ['EEG_C3-R', 'EEG_C4-R', 'EOG_LOC-R', 'EMG_L-EMG_R']
print(record.sampling_rate)  # 200.0 Hz
print(signals.shape)        # (エポック数, 6000, 4)；エポック数は記録による
print(record.stages.shape)  # (エポック数,)
```

1エポックは30秒です．配列の軸は，エポック番号・エポック内のデータポイント・チャンネルの順です．
Loaderが返すテンソルは `(エポック, チャンネル, データポイント)` ですが，
授業用の `load_sleep_record` が `(エポック, データポイント, チャンネル)` に並べ替えています．
チャンネルは保存順に依存せず，名前で選びます．FlowやSpO2，イベント信号はこの4チャンネルに入りません．

脳波 `EEG_C3-R` を取り出す例です．

```python
channel_index = record.channel_names.index("EEG_C3-R")
c3_signal = signals[:, :, channel_index]
epoch = 0
one_epoch = c3_signal[epoch]
```

任意のチャンネルを指定する場合は，次のように読み込みます．

```python
record = load_sleep_record(npz_path, channels=["EEG_C3-R", "EOG_LOC-R"])
print(record.signals.shape)  # (エポック数, 6000, 2)
```

正解ステージはAASMに基づき，`0=Wake, 1=REM, 2=N1, 3=N2, 4=N3, -1=Unknown` です．
波形表示ではUnknownも元の位置に残します．学習・評価時には設定によりUnknownを除外します．

`record.metadata.signal_info` の2列目には，元のフィルタと標準化時のフィルタの情報が入っています．
配布信号は標準化時にフィルタ処理されており，未処理の生波形ではありません．
フィルタの実験ではこの情報も確認してください．

## 生体信号の可視化

Python上の可視化にはmatplotlibを使います．
横軸を秒にする場合は，サンプル番号を `record.sampling_rate` で割ってください．

テンプレートの `src/lecture_09_exp_1_visualize_signal.py` には読み込み処理を実装済みです．
次の `NPZのパス` は，上の例で表示した実際のファイルパスに置き換えてください．

```bash
python src/lecture_09_exp_1_visualize_signal.py -f NPZのパス -e 0
```

読み込んだ `signals`，`sampling_rate`，`channel_names`，`stage` を使って，
仮の正弦波を実際の生体信号のプロットに置き換えてください．
出力先は `results/plots/` です．
